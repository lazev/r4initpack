PROBLEMA: Classe Security usa MD5 truncado para gerar chaves
SEVERIDADE: MEDIO
ARQUIVO: php/security.class.php, linha 22
STATUS: Nao corrigido

------------------------------------------------------------------------

O QUE ACONTECE:

A geracao de chave faz:

    $md5 = substr(md5($cod . $id . $passkey), 5, 10);

Problemas:
- MD5 e criptograficamente quebrado (colisoes conhecidas)
- Apenas 10 caracteres hexadecimais do hash sao usados
- Isso equivale a ~40 bits de entropia, facilmente brute-forceavel
- Com cod e id conhecidos (geralmente sao), basta testar passkeys

------------------------------------------------------------------------

COMO CORRIGIR:

Trocar MD5 por hash_hmac com SHA-256 e usar mais caracteres:

    $hash = substr(hash_hmac('sha256', $cod . $id, $passkey), 0, 32);

Isso sobe de ~40 bits para ~128 bits de entropia.

O formato de saida (base64 com pontos) pode ser mantido, apenas
trocando a funcao de hash internamente.

------------------------------------------------------------------------

CUIDADO AO CORRIGIR:

Chaves ja geradas com MD5 ficarao INVALIDAS apos a troca. Se algum
sistema armazena chaves geradas pelo metodo antigo, elas nao serao
mais reconhecidas pelo extractKey.

Opcoes:
A) Trocar de uma vez e regenerar todas as chaves existentes
B) Tentar validar com SHA-256 primeiro, e se falhar tentar com MD5
   (periodo de transicao), logando um aviso para migrar
