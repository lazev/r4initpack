STATUS: CORRIGIDO

O QUE FOI CORRIGIDO:

1. requireReferer agora aceita true para usar ROOT_URL automaticamente
   (antes aceitava apenas 'https' que qualquer site HTTPS passava)

2. CSRF token implementado:
   - r4iniend.php gera token na sessao e valida em requisicoes POST
   - gatekeeper.js.php envia o token ao frontend via _CONFIG.csrfToken
   - R4.getJSON() e R4.sendBlob() enviam header X-CSRF-Token automaticamente

3. Para desativar a validacao CSRF em um endpoint especifico (ex: login),
   usar a opcao requireCsrf: false no $_CONFIG daquele endpoint:

    $_CONFIG = [
        'requireLogin' => false,
        'requireCsrf'  => false  // sem sessao pre-existente, ex: login
    ];

   Isso e seguro para o login pois um ataque CSRF exigiria que o atacante
   soubesse as credenciais da vitima, tornando o ataque inutil.

4. Para desativar rapidamente a validacao CSRF em TODOS os endpoints,
   comentar o bloco no r4iniend.php (linhas 19-29).
