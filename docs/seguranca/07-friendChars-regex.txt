PROBLEMA: friendChars permite injecao no pattern da regex
SEVERIDADE: BAIXO
ARQUIVO: php/r4.class.php, linha 146
STATUS: Nao corrigido

------------------------------------------------------------------------

O QUE ACONTECE:

O metodo friendChars insere $allowStr diretamente no pattern:

    return preg_replace('/[^A-Z0-9-_'. $allowStr .']/i', '', $string);

Se $allowStr contiver caracteres especiais de regex como ] ou \,
o pattern quebra ou permite comportamento inesperado.

Exemplo:
    R4::friendChars($input, '].*');
    // Pattern vira: /[^A-Z0-9-_].*]/i
    // Regex completamente diferente do esperado

------------------------------------------------------------------------

COMO CORRIGIR:

Escapar o parametro com preg_quote:

    return preg_replace('/[^A-Z0-9-_'. preg_quote($allowStr, '/') .']/i', '', $string);

------------------------------------------------------------------------

RISCO REAL:

Baixo. Este parametro normalmente e definido pelo desenvolvedor no
codigo-fonte (ex: ' ' para permitir espacos), nao vem de input do
usuario. Mas e uma boa pratica corrigir para evitar surpresas.
